[ 01 : VISION & GAMEPLAY ]

THE PREMISE & CORE VISION

A satirical noir detective game with a daily habit loop.

  • The Daily Micro-Crime: Every 24 hours at midnight local time, a bizarre micro-crime occurs (e.g., swapping ancient Roman spoons for neon plastic sporks, reprogramming clocktower cuckoos to scream like roosters).
  • The Interrogation Table: You sit across from an eccentric guilty suspect with a compulsive speech quirk and a fabricated cover story.
  • Question Token Economics: You start with 5 Question Tokens. Every interrogation costs 1 token. You must interrogate smartly and corner them into an undeniable contradiction.
  • The Viral Habit Loop: One shared global daily case, Wordle-style investigation teletype share grids, and high-stakes detective streak scores.
Authentic 1980s Retro CRT Terminal Main Menu & Difficulty Protocol Selector
[ 02 : SYSTEM ARCHITECTURE ]

5-AGENT AUTONOMOUS AI ECOSYSTEM

1. CASE ARCHITECT AGENT
Procedurally generates solvable micro-crimes, immutable 3-fact dossiers, true timelines, and guaranteed catchable weak points seeded daily.
2. SUSPECT AGENT
Autonomous persona agent. Internalizes cover stories, tracks speech quirks, maintains lie consistency, and projects emotional states (calm, nervous, rattled).
3. CLAIM EXTRACTOR AGENT
Synthesizes spoken answers into atomic subject-predicate-object claims logged into ChromaDB RAG for instant retrieval.
4. CONTRADICTION JUDGE
Strict legal evidentiary judge. Uses Chain-of-Verification (CoV) to enforce direct physical mutual exclusivity between testimony and facts.
5. NOIR NARRATOR AGENT
Hardboiled 1980s narrator. Evaluates detective performance, delivers cryptic case hints, and writes courtroom verdicts.
[ 03 : INVESTIGATION WORKFLOW ]

THE CLASSIFIED CRIME DOSSIER

Before stepping into the interrogation room, inspect the facts.

  • Immutable Forensic Truths: The police crime lab provides exactly 3 verified forensic facts that cannot lie (e.g., serial stamped gears, mud bootprints, audio cassettes).
  • Procedural Pixel Suspect Portraits: Generated dynamically by the custom Alibi Character Kit based on physical traits (hair, trench attire, monocles).
  • Quirk Briefing: Highlights the suspect's compulsive speech mannerisms to help you detect nervousness and slips.
Classified Briefing: Suspect Mugshot, Physical Traits, & Immutable Dossier
[ 04 : THE INTERROGATION ROOM ]

LIVE WIRE INTERROGATION TABLE

Direct, unscripted neural dialogue with the suspect.

  • Live Dialogue Wire: Every question typed is processed through the local neural LLM, generating real-time in-character responses.
  • Nervousness Cues & Audio: Suspect emotional shifts trigger audio clicks and CRT expression updates when pressed on weak points.
  • Coin Token Tracker: Authentic pixel-art token coins indicate remaining interrogation stamina, flashing critically when depleted.
  • Cryptic Noir Hints: When stuck, spend 1 token to request guidance from the Hardboiled Noir Narrator.
Interrogation Wire: CRT Monitor, Pixel Portrait, Tokens, & Dialogue Transcript
[ 05 : THE CORE PUZZLE ]

THE CONTRADICTION INDICTMENT

Pair a suspect quote directly against an immutable fact.

  • Point-and-Click Indictment: Select the exact quote from the suspect's transcript and the conflicting dossier fact.
  • Strict Chain of Verification: The Contradiction Judge checks mutual exclusivity: can both Claim A and Claim B coexist in physical reality?
  • Zero Sycophancy: Circumstantial suspicion is NOT enough. If the suspect didn't make a direct, physically impossible assertion, the judge rules INVALID.
  • Penalty Token Enforcement: False accusations penalize 1 token (2 on Hardboiled). Run out of tokens, and you lose!
Accusation Indictment: Selecting Contradictory Quotes & Immutable Evidence

VERDICT COMMENDATION & CONFESSION

CAREER MEMORY & DAILY LOCKOUT
